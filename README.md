<h3>💳 <a href="https://github.com/AkshithPeri7/hackerrank-orchestrate-september26">AffordIQ — Buy or Wait?</a></h3>

**Original HackerRank Hackathon Project**

I developed AffordIQ during the HackerRank hackathon. The challenge required participants to upload their project files into the provided challenge repository, which is why the project is hosted there.

The system reconstructs financial timelines, projects 90-day cash flow, evaluates and ranks payment strategies, and validates that essential expenses and minimum balances remain protected. Its documented scoring path is deterministic and rule-based.

**Focus:** Financial modelling · Cash-flow projections · Payment strategy evaluation · Financial safety checks

</td>
<td width="50%" valign="top">

<h3>🌾 <a href="https://github.com/AkshithPeri7/AgriScan">AgriScan</a></h3>

**Agriculture Assistance Platform**

An agriculture-focused platform combining crop-disease assistance, treatment guidance, multilingual support, and geospatial discovery of agricultural services.

The repository documents a React/Vite frontend, FastAPI backend, PostgreSQL/PostGIS, and a TFLite-ready inference wrapper. The inference component is currently a stub, so it is not represented here as a completed or validated ML model.

**Technologies:** React · Vite · Python · FastAPI · PostgreSQL · PostGIS
